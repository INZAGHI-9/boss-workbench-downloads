[Mac 6.4.0 发布说明、附件与校验收据](https://github.com/INZAGHI-9/boss-workbench-downloads/releases/tag/v6.4.0)。Mac独立更新频道为6.4.0，Windows频道保持6.3.2。

Mac6.4.0新增历史任务“查找候选人”，检索已保存的人选、完整简历与来源任务，支持 `+` 同时包含、`-` 排除、`、` 任一组命中及命中高亮。精准工作台区分搜索、本批联系和整轮结束，改善批次结果与沟通入口；沟通任务显示同岗位历次已核验、按人去重的累计成功／淘汰人数。修复桌面网络 EINVAL 导致安全退出请求悬挂的问题。历史查询只读，首次冷查询仍可能需要等待。

保留6.3.5的历史评分与材料显示、精准建联岗位核验和启动维护优化，以及6.3.3的安全验证停止与提醒。Windows6.3.2仍提供精准寻访选人、联系与追加、唯一目标选岗及已确认消费展示；本次未构建或推广新版Windows，不将Mac新增功能视为Windows已发布。

已有用户可从顶栏“更新”检查下载，就绪后点击“重启并更新”。6.3.5→6.4.0相邻差量为370454字节，历史独立差量链在后台连续应用，最终只启动最新版。旧Mac6.1.1需安全退出后手动安装当前DMG，之后使用独立Mac频道；6.1.0旧更新器元数据有误，也应手动覆盖安装。

6.4.0没有新SQL迁移，schema10不变；旧于6.2.0仍可能涉及既有schema4→10升级。未知结构和身份冲突仍拒绝，不手工改库或删除旧数据。原历史、材料、预算、未知动作与配置保留；更新不自动恢复招聘任务或补发未知动作。覆盖前正常安全退出并备份业务数据；结构升级不能通过覆盖旧应用撤销，降级需升级前备份。

Mac640最终包、4238资源、应用树和严格签封已核对；四件新附件与十二条历史delta完整远端回读通过，公开频道及当前差量已匿名核同。6.3.5→6.4.0全新隔离合成原生升级PASS，确认新版服务和工作台，预算、unknown与profile保留。该安装验证使用隔离传输，不代表公网原生升级或用户日常应用已更新。真实招聘、真实模型、Windows原生与全部旧版逐个原生安装未测。Mac为ad-hoc签封且未公证。

Windows6.3.2已完成本地原生构建、5675项运行资源核对、两次隔离服务重启及合成存储回放；最终安装向导、已安装GUI和旧版主动更新未测，额外桌面回归仍有5项环境/历史夹具失败，原生通知未测，Windows未签名。校验见各版macos-SHA256SUMS.txt或windows-SHA256SUMS.txt。发行收尾按各平台保留当前全量安装包，全部独立delta和版本清单保留。

安装包自带Python、Node和数据库，客户无需开发工具。首次启动下载缺失浏览器组件、使用模型和BOSS仍需网络及相应账户。旧客户端对新版评分载荷的展示未验证。

目标系统：Windows10 1903+ x64、Windows11 x64；Mac M系列macOS14+。程序文件可从安装包提取，Git源码仓库私有不代表安装包具备源码保密能力。
