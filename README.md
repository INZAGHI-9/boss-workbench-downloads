6.5.0没有新SQL迁移，schema10不变；旧于6.2.0仍可能涉及既有schema4→10升级。未知结构和身份冲突仍拒绝，不手工改库或删除旧数据。原历史、材料、预算、未知动作与配置保留；更新不自动恢复招聘任务或补发未知动作。覆盖前正常安全退出并备份业务数据；结构升级不能通过覆盖旧应用撤销，降级需升级前备份。

最终包4435项资源、应用树、严格签封和DMG已核对。四件新附件与13条历史delta完整远端回读通过，公开Mac频道及当前差量匿名核同，Windows频道字节保持。6.4.0→6.5.0全新隔离原生升级通过，新版服务与工作台、profile、预算和unknown保留，未自动续跑。这使用隔离传输，不代表公网原生升级或用户日常应用已更新。

真实单账号登录与安全退出已验；真实双账号A→B→A、真实招聘、付费模型、Windows原生与全部旧版逐个安装未测。Mac为ad-hoc签封且未公证。前端最后全量1160通过/2失败，补修后相关19项和Workflow15项通过；未重跑第三轮全量。
