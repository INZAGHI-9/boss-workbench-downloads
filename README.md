[Mac 6.3.0 发布说明、附件与校验收据](https://github.com/INZAGHI-9/boss-workbench-downloads/releases/tag/v6.3.0)。Mac 独立更新频道提供 6.3.0；Windows/共享频道保持 6.1.2。

Mac 6.3.0 新保存策略默认采用统一全文评分，一次主审给出总分和同次评语；旧冻结任务与历史保留原合同。联系队列即时展示阶段进度，可继续选人追加；原联系结果未知时自动只读核实，不补发。平台已解锁姓名与当次费用记录同步展示，消费金额不额外核实。沿用身份、预算、去重和写后证据保护，不自动续跑任务。

Mac 6.2.2 通过相邻差量升级至6.3.0；6.1.2–6.2.1通过独立差量链升级，历史差量在后台连续应用，最终只安装一次最新版。旧Mac6.1.1先升级至过渡6.1.2，再检查独立频道；6.1.0的旧更新器元数据有误，应安全退出后手动覆盖安装。6.3.0不新增数据库迁移；旧于6.2.0的版本仍涉及schema4→10升级，未知结构和身份冲突仍拒绝，不手工改库或删除旧数据。本次保留历史安装附件和差量。

最终资源、DMG和严格签封已核对，本地6.2.2→6.3.0隔离原生差量更新核心验收通过：执行旧客户端退出、包外助手、差量替换、系统重开和新版服务/工作台确认，合成历史、预算与未知动作保留；分发使用隔离fixture，不等于日常安装应用已更新。公开附件与频道按发行收据核验。Windows本轮未进行原生验证。Mac为ad-hoc签封且未公证，Windows未签名。校验见各版 `macos-SHA256SUMS.txt` 或 `windows-SHA256SUMS.txt`。

安装包自带Python、Node和数据库，客户无需开发工具。首次启动下载缺失浏览器组件、使用模型和BOSS仍需网络及相应账户。更新不自动恢复招聘任务或补发未知动作，请保留原数据目录。覆盖前正常安全退出并备份业务数据；结构升级不能通过覆盖旧应用撤销，降级需升级前备份；旧客户端对新版评分载荷的展示未验证。

目标系统：Windows 10 1903+ x64、Windows 11 x64；Mac M系列macOS14+。程序文件可从安装包提取，Git源码仓库私有不代表安装包具备源码保密能力。
