Mac6.3.2修复精准寻访通过人员待选误拦、普通无报价时畅聊回退、唯一目标选岗和已确认消费展示。联系复用完整材料与已确认资格，常规零模型、单次详情逐人原生开聊；独立清场、执行中追加与跨批六类结果交付。姓名简称、遮罩/解罩及同人履历微改保留兼容，明确完整姓名冲突拒绝；未知动作只读核实，不补发。源码真实三人连续成功与执行中追加均通过，旧失败和unknown保留，不将未完成名单显示为全部成功。

Mac6.3.1通过326454字节相邻差量升级至6.3.2；历史独立差量链在后台连续应用，最终只安装一次最新版。旧Mac6.1.1先升级至过渡6.1.2，再检查独立频道；6.1.0旧更新器元数据有误，应安全退出后手动覆盖安装。6.3.2不新增数据库迁移，schema10不变；旧于6.2.0仍涉及schema4→10升级，未知结构和身份冲突仍拒绝，不手工改库或删除旧数据。发行收尾按各平台保留当前全量安装包，保留全部独立delta和版本清单。

最终包字节、应用树和严格签封已核对，四件候选附件完整远端回读通过；6.3.1→6.3.2隔离合成原生差量升级PASS，确认新版服务和工作台，历史、预算、unknown与profile保留。该安装验证使用隔离传输，不冒充公网原生升级，也不代表日常应用已更新。公开频道和当前差量已匿名回读。Windows本轮未实测，原生通知未测；Mac为ad-hoc签封且未公证，Windows未签名。校验见各版macos-SHA256SUMS.txt或windows-SHA256SUMS.txt。

安装包自带Python、Node和数据库，客户无需开发工具。首次启动下载缺失浏览器组件、使用模型和BOSS仍需网络及相应账户。更新不自动恢复招聘任务或补发未知动作，请保留原数据目录。覆盖前正常安全退出并备份业务数据；结构升级不能通过覆盖旧应用撤销，降级需升级前备份；旧客户端对新版评分载荷的展示未验证。

目标系统：Windows10 1903+ x64、Windows11 x64；Mac M系列macOS14+。程序文件可从安装包提取，Git源码仓库私有不代表安装包具备源码保密能力。
