[6.5.1 发布说明、附件与校验收据](https://github.com/INZAGHI-9/boss-workbench-downloads/releases/tag/v6.5.1)。Mac独立更新频道为6.5.1，Windows频道保持6.3.2。功能为跨平台共用实现，本次只发行Mac安装附件，Windows未构建或验证。

6.5.1采用账号身份行方案 A：姓名字标、姓名和公司两行，调整比例与留白，不采集头像。同时修复未登录时设置/诊断被隐藏、安装按钮依赖账号活动列表和更新状态失败连带禁用浏览器工具。基础功能不依赖BOSS登录或模型配置；账号业务隔离和安装前全局安全预检保持。此前四条招聘路径的账号恢复、换号终止、历史隔离、定时安排与工作台能力保留。商业服务尚未上线，本版不启用商业授权。

已有用户可从顶栏“更新”检查下载，就绪后点击“重启并更新”。 旧6.5.0在未登录时有安装按钮误拦截，需先登录再升级，或从菜单栏安全退出后使用当前DMG安装。历史独立差量链在后台连续应用，最终只启动最新版。旧Mac6.1.1需安全退出后手动安装当前DMG，之后使用独立Mac频道；6.1.0旧更新器元数据有误，也应手动覆盖安装。

6.5.1没有新SQL迁移，schema10不变；旧于6.2.0仍可能涉及既有schema4→10升级。未知结构和身份冲突仍拒绝，不手工改库或删除旧数据。原历史、材料、预算、未知动作与配置保留；更新不自动恢复招聘任务或补发未知动作。覆盖前正常安全退出并备份业务数据；结构升级不能通过覆盖旧应用撤销，降级需升级前备份。

最终包4435项资源、256个controller文件、应用树、严格签封和DMG已核对。4件当前附件与14条历史delta完整远端回读通过，Mac651频道及当前差量匿名核同，Windows632频道字节保持。640→650→正式651隔离原生升级通过，新服务与工作台确认，历史、预算和unknown保留；正式651未登录/未配置模型/账号列表400下的设置、诊断、草稿及真实按钮前向安装通过。前向目标为同源本地合成652，不发布652。这使用隔离传输，不代表公网原生升级或日常安装已更新。

相关82项、typecheck/build通过，不称全仓全绿。真实单账号登录与安全退出沿用650已验范围；真实双账号A→B→A、真实招聘、付费模型、Windows原生与公网原生升级未测。Mac为ad-hoc签封且未公证。

Windows6.3.2已有本地原生构建和运行资源核对，最终安装向导、已安装GUI和旧版主动更新未测，Windows未签名。校验见各版macos-SHA256SUMS.txt或windows-SHA256SUMS.txt。发行收尾按各平台保留当前全量安装包，全部独立delta和版本清单保留。

安装包自带Python、Node和数据库，无需开发工具。首次启动下载缺失浏览器组件、使用模型和BOSS仍需网络及相应账户。目标系统：Windows10 1903+ x64、Windows11 x64；Mac M系列macOS14+。源码仓库私有不代表安装包具备源码保密能力。
