[6.5.2 发布说明、附件与校验收据](https://github.com/INZAGHI-9/boss-workbench-downloads/releases/tag/v6.5.2)。Mac独立更新频道为6.5.2，Windows频道保持6.3.2。功能为跨平台共用实现，本次只发行Mac安装附件，Windows未构建或验证。

6.5.2修复同一岗位更新JD、薪资和经验资料后的采集与后续流程，继续沿用已保存画像和策略。修复启动恢复、精准搜索初读、收藏分页与同人联系、完整简历评分和单人故障隔离，以及预算正常结束和报告释放入口。模型预算耗尽保留未处理名单供人工继续；明确当前选岗冲突且无法纠正时停止联系，缺组件不增加拦截。历史故障重处理仅供开发调试，用户入口隐藏；精准旧轮人工选人、继续未处理批次及未知结果核实保留。商业授权不启用。

已有用户可从顶栏“更新”检查下载，就绪后点击“重启并更新”。 旧6.5.0在未登录时有安装按钮误拦截，需先登录再升级，或从菜单栏安全退出后使用当前DMG安装。历史独立差量链在后台连续应用，最终只启动最新版。旧Mac6.1.1需安全退出后手动安装当前DMG，之后使用独立Mac频道；6.1.0旧更新器元数据有误，也应手动覆盖安装。

6.5.2没有新SQL迁移，schema10不变；旧于6.2.0仍可能涉及既有schema4→10升级。未知结构和身份冲突仍拒绝，不手工改库或删除旧数据。原历史、材料、预算、未知动作与配置保留；更新不自动恢复招聘任务或补发未知动作。覆盖前正常安全退出并备份业务数据；结构升级不能通过覆盖旧应用撤销，降级需升级前备份。

最终包4438项资源、259个controller文件、应用树、严格签封和DMG已核对。4件当前附件与15条历史delta完整远端回读通过，Mac652频道及当前差量匿名核同，Windows632频道字节保持。正式651→652隔离原生升级通过，新服务与工作台确认，历史、预算和unknown保留；使用隔离传输，不代表公网原生升级或日常安装已更新。

源码回归1374个Python节点通过，43个失败均在main复现，3个非适用跳过；前端唯一新增夹具失败已修复并补验。双轴审查发现的两项问题已修复并独立复核。不称全仓全绿。真实Mac招聘验收沿用既有小样本；同人模型兜底自然现场、真实退出登录新提示、Windows原生与公网原生升级未测。Mac为ad-hoc签封且未公证。

Windows6.3.2已有本地原生构建和运行资源核对，最终安装向导、已安装GUI和旧版主动更新未测，Windows未签名。校验见各版macos-SHA256SUMS.txt或windows-SHA256SUMS.txt。发行收尾按各平台保留当前全量安装包，全部独立delta和版本清单保留。

安装包自带Python、Node和数据库，无需开发工具。首次启动下载缺失浏览器组件、使用模型和BOSS仍需网络及相应账户。目标系统：Windows10 1903+ x64、Windows11 x64；Mac M系列macOS14+。源码仓库私有不代表安装包具备源码保密能力。
